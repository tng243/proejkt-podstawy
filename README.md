## CS2 Inventory Viewer

A desktop application that allows users to view their Counter-Strike 2 weapon skin inventory in a clean, modern interface. Built with Python and CustomTkinter, it provides a seamless experience for checking item collections, their current market value, and recent price trends.

### Key Features
* **Inventory Fetching:** Connects directly to the Steam API to retrieve the user's CS2 items.
* **Visual Browser:** Displays items in a responsive, tile-based layout complete with official weapon icons.
* **Live Pricing & Trends:** Integrates with SteamAPIs to fetch real-time market prices and allows users to compare price history over the last 15 days.
* **Modern UI:** Built with CustomTkinter for a sleek, dark-mode desktop experience.
